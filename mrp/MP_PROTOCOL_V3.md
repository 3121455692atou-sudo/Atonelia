# 联机协议 v3

本版本要求新建联机房间；协议 v2 房间及其原文件不转换、不修剪、不自动升级。单机存档 schema5、世界规则版本不因此变更。

v3 差分带必需的 `$v:3` 标记。automation 按子字段传输；recent 与 receipts 有界数组只发送追加和裁剪。客户端应用后状态与服务器原视图逐字一致，游戏规则与计算没有改变。

SSE 连接必须明确请求 `?v=3`，旧客户端缺少/错版本得到409，不接收无法理解的增量。新客户端拒绝旧大厅/init版本；旧/缺失/未知及嵌套错版本差分在修改镜像前拒绝。双方应一并刷新到新版本并新建房间。

重连仍使用原有 EventSource 有序传输、Last-Event-ID 回放与超出缓冲后的完整 init 重同步。本次不声称支持任意脱离 SSE 的乱序差分；不能自行重排或重复应用不带完整快照的增量。
