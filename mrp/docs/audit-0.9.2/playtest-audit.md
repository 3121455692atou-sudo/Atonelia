# 实际对局与事件验收说明

本轮采用实际游戏命令、按日推进和真实事件选择验证玩法。审计脚本不直接修改现金、日期、模型能力、研究成果或事件队列。有限的代表性对局用于验证因果链和执行契约，不把它解释为随机玩家的事件发生率或全面平衡性保证。

### 未弹出的里程碑：只读条件审阅

49 / 64 指实际遇到的里程碑弹窗种类，包含自家完成和对手先完成，不能写成“49 项玩家成就”。未弹出的 15 项中，3 项已在本批次存档中静默记账：`ms_from_scratch` 出现在 NovelAI 2024 的 Kayra 和两个 RWKV 2025 开局；`ms_many_langs` 出现在 ElevenLabs 2025 开局；`ms_personality` 出现在三局首月经营。`initMilestones` 和首次月结本来就会记录已经具备的条件，避免开局重复弹窗；这些静默记录不增加本报告的实际弹窗次数。

对本轮来源与容量修复最敏感的三项另外做了只读核对，没有发现逻辑上被封死：

| 里程碑 | 条件证据 | 证据边界 |
|---|---|---|
| `ms_from_scratch` 从零训练的小模型 | 要求总参数 ≤15B、写作 ≥55，拒绝带模型蒸馏老师或蒸馏快照的模型。自研预训练新底座不携带这些字段。NovelAI 2024 的合法 14B / 4T 自研预览写作底座约 52.05、后训上限约 68.05；已有开局静默记录也证明判定没有一律拒绝小模型 | 新配置仅做预览，未另跑完整发布路线 |
| `ms_flash_catchup` 小模型追上去年旗舰 | 要求发布 small 角色模型且综合能力超过一年前最强对手，并未要求 ≤15B。Qwen 2025 合法配置：DeepSeek-R1 老师、70B / 6T 学生，预览综合 73.28；2024-01 最强对手 GPT-4 Turbo 为 70 | 是合法配置和能力比较的条件证据，不是实际弹窗；默认顾问偏向 14B，未选择此路线 |
| `ms_small_reasoner` 小模型也会推理 | 要求 ≤15B、已掌握 textbook、数学 ≥60，没有禁止蒸馏。Qwen 2025 的 14B / 6T R1 学生预览数学 79.3、textbook 已掌握，纯 `playerMatch` 判断通过 | 只读预览和条件判断，不计入触发覆盖 |

其他未遇项主要要求专门选择 MoE/RNN 小模型、安全专训、更高的综合能力，或图像审美/语音表现力。读代码未见这些条件互相矛盾，但没有完成相应专门路线，不能宣称已经实玩验证。作为上限检查，2026 Claude/GPT 训练中模型的综合上限约 96、安全上限 99，Fable 综合上限约 97.6；Midjourney 2026 的审美上限 98，ElevenLabs 2026 的表现力上限 96，均为高门槛保留了数值空间。RWKV 2026 现有 7B 快照的综合上限只有 52.4，低于 RNN 追赶要求的 55，必须考虑新的 RNN 底座或其他成长来源，不能把原底座无限后训当作可达证明。一次发布最多弹出一个自家里程碑，因此满足条件也可能需要后续再次发布才能轮到。

## 复跑

```bash
npm test
node scripts/audit_gameplay.mjs --out tmp/gameplay-audit
node scripts/audit_gameplay.mjs --only expansion-comeback,early-reasoning --out tmp/rare-events
```

完整矩阵包含 35 局：18 局按游戏内建议经营，17 局通过公开操作专门诱发压力或特定事件。覆盖 2023—2026 四个剧本、语言/图像/音乐/语音四种模态、不同国家与资源规模、史实发布和反应式竞争两种模式。每局有独立角色、种子和策略，定义在 `scripts/audit_gameplay.mjs` 的 `PROFILES`。

脚本生成 `report.json` 和 `summary.md`。JSON 保存每次实际事件、选择、操作、月报、状态转换和源码 SHA-256。结束时再次计算源码哈希；若运行途中核心文件变更，`integrity.sourceStable` 为 `false`，进程以失败码退出，不能把混合版本的结果作为最终验收。

## 三种证据必须分开

| 类型 | 做法 | 计入事件触发次数 |
|---|---|---|
| 普通游玩 | 从新局开始，每周遵循游戏内建议，处理实际出现的事件 | 是，`ordinary` |
| 操作诱发 | 从新局开始，故意压低推理份额、采购风险数据、隐藏量化、扩张订单、专注提前研发等 | 是，`induced` |
| 选项分支探测 | 克隆已经真实遇到事件的存档，分别执行每个可用选项，并验证禁用选项原子拒绝 | 否，单列 `probes` |

`tests/test_event_reachability.mjs` 中的付费选项压力检查，会在真实事件存档上通过股票交易降低可用现金；融资、走私、蒸馏和参数边界检查也均调用公开命令。它们不伪造事件触发，不用“往 queue 塞一个事件”证明事件可达。

## 每次实际遇到事件时检查

- 查看事件不改变存档，避免反复打开界面消耗随机数或结算资源。
- 至少有一个可选项；即使资金不足，也能通过免费或保守选项继续游戏。
- 每个启用选项可执行并消费当前事件；禁用选项执行失败且存档不变。
- 数值保持有限，时间可以继续推进。
- 单次成就、行业里程碑不会重复弹出或重复给奖励；空队列再次确认会被拒绝。
- 新闻单独统计。很多行业大事只有新闻，不能当成“漏弹事件”。个人历史文案由里程碑复用，也不能拿旧 `history` 队列的缺席认定不可达。

## 重点因果链与修复

| 链条 | 实际验证内容 | 本轮结论 |
|---|---|---|
| 数据 → 训练 → 发布 → 灰度 → 里程碑 | 从零公司采购语料、完成预训练、发布后全量上线，触发自己的里程碑 | 公共操作回归覆盖 |
| 中国公司备案 | 训练安全能力、提交备案、等待实际月结通过、开放公众聊天 | 以服务状态变化验证，不能把未使用的旧 `filing` 弹窗定义计作失败 |
| 连续拥堵 → 429 | 连续两个月真实 429 数据触发告警 | 公共操作回归覆盖 |
| 429 → 扩容 | 确认租卡后先有订单，交付日前实际卡数不增加 | 验证交付时延，不能靠剧情直接加算力 |
| 429 → 透明量化 | 使用免费分流选项，路由解锁且服务容量改变，物理 GPU 数不变 | 低资源公司仍可继续 |
| 隐藏量化 → 曝光 → 否认 → 诉讼 | 多月积累证据后真实曝光，否认产生集体诉讼并结案 | 正反结果由实际法律流程决定 |
| 风险版权数据 → 诉讼 | 语言、音乐、图像分别采购相应风险数据并实际经营 | 样本未遇到不代表不可达，报告保留各分支触发数 |
| 蒸馏完成 → 发布 → 上线 | 老师、参数、数据量和来源一路保留；继承版本不能冒充从零训练 | 已补来源冻结与归因回归 |
| 合成/开源蒸馏数据占用算力 | 工作量按实际 GPU 按日累积；少卡超过名义交期也不能免费到货；用户推理份额不被改写 | 使用独立生成桶，到货前必须完成工作；暂停保留进度并释放训练算力 |
| 小团队生成任务阻塞 | RWKV 的 67 张卡接入生成任务后，顾问暂停大任务，让安全训练与备案继续 | 保持 450 天原验收窗口；真实 2023-09-10 提交、11-01 通过备案 |
| 灰色采购 → 到货/扣货 | 在途不算持有；到货仅入库一次；扣货不留下虚假库存 | 回归覆盖两种真实随机分支 |
| 融资/IPO/破产/董事会换人/终局 | 融资延期到账并稀释；IPO 挂牌；拒绝经营与持续烧钱产生不同结局 | 分开检查，未把时间截止的 `playing` 当作通关 |
| 普通后训练数据 | 在途或现金不足时预览禁用，与实际购买结果一致；到货后可再次补充 | 已统一 `datasetAvailable` 契约 |
| 非法预训练配置 | NaN、无穷、非正数及字符串输入 | 公开命令拒绝，存档不变 |

### 绝境翻盘不是造条件

`expansion-comeback` 使用 Mistral、2023 剧本、种子 186。先采购大批 H100，订单长交期期间现金被占用，随后实际触发 `runway`。选择融资后恢复按建议采购数据、训练、发布和经营，估值从危机后的低谷增长到四倍以上，实际触发 `super_comeback`。危机、股权稀释、模型发布和恢复都由正常结算产生。

### 推理先行者：能力可达，但原先会被演出冷却吞掉

`early-reasoning` 使用 GPT、2023 剧本、种子 187。公开操作路径是提前研究 DPO → GRPO → 推理 RL，同时采购语料、融资、租卡，并实际训练 671B 稠密、12T token 新底座。科研空档和研究完成后专注数学训练，先发布达到数学 80 的模型获得自己的推理里程碑，再继续训练并第二次发布数学超过 84 的版本。完整灰度后，在 2024 年 9 月前满足先行者条件。

原逻辑按目录找到一个超事件就返回，并在检查条件之前执行 60 天冷却。同月的 OpenRouter 成就排在推理先行者之前，导致已完成的限时资格永久消失。

现在每个月先把所有首次满足的超事件记入 `flags.superEarned`，保存达成日、当时的模型和 IPO 涨幅。冷却只决定何时演出；先达成的先演，同月按原目录顺序。派发时保留原有 `super:<id>` 标记，避免存档重载或后续月结重复入队。延期演出的文本注明原达成日期，并使用当时的模型名，不能把几个月后的纪念活动误写成那时才取得成绩。回归从实际月结后捕获“先行者资格已取得、演出尚未入队”的存档，序列化、迁移后继续推进，验证限时资格仍只演出一次。60 天冷却约束两次超事件入队的间隔，不能误写为取得资格后固定再等 60 天。

## 浏览器操作验收

`scripts/ui_smoke.mjs` 在桌面 1440 像素与手机 390 像素宽度实际点击界面，覆盖：

- 新局选择史实发布/反应式竞争，真实发布后出现可解释的对手应对。
- 进入后台、服务、对手和榜单，价格预览即时更新且不污染上月结算记录。
- 蒸馏表单的五档数据量、可用架构、非法 MoE 激活量禁用与原因。
- 实际开工，第 3 天保存重载保持项目快照，第 7 天完成，再发布小模型并走完灰度。
- 老师总参数/激活参数、老师生成数据算力、学生训练算力、冻结来源和最短工期可见。
- 实际拖动推理与出租滑杆；推理、训练、数据生成、出租四项物理 GPU 合计保持总量，推理份额只分配剩余自用卡。
- 真实下单合成数据，在后台暂停、保存重载保留进度与暂停状态，再从主页继续生成；暂停立刻释放训练算力。
- 缺失美术时显示本地文字/CSS 降级，不向外部图片站请求资源。
- 页面没有未捕获的 JavaScript 异常、没有横向溢出，旧存档迁移和保存重载可用。

最终冻结版的 11 组 UI 验证全部通过，报告见 [ui-report.json](../audit/ui-report.json)。桌面和手机都无未捕获的页面 JavaScript 异常、无外网资源请求，价格预览保持上月结算记录不变，生成暂停/重载/恢复、蒸馏完成/发布、旧存档加载均通过。缺失美术的本地请求会走占位图降级，不把预期的缺图请求与脚本异常混为一谈。截图只作内部目检，不随项目交付。

浏览器依赖与路径通过环境变量提供，不纳入普通 `npm test`：

```bash
UI_BASE_URL=http://127.0.0.1:8767 \

UI_QA_DIR=/path/to/qa-output \
UI_FONT_PATH=/optional/path/to/chinese-font.otf \

```

榜单显示口径也经过 UI 验证：同分同名次；全榜 0 分提示量程下限；专项第一不等于综合 SOTA；调用量和性价比允许小模型领先。对手综合能力取已经发布的最强版本，并另列最新发布，避免新小款覆盖旧旗舰造成“公司能力倒退”的误读。

## 解释边界

最终计数应以对应发布版本生成的 `report.json` 为准。中间探查报告用于保留修复前证据，不与最终版本次数混合。真实触发次数和选项探测次数始终分开；达到脚本天数上限而仍在经营的对局明确记作 `playing`。本轮关注可达性、重复奖励、事件阻塞和资源结算，不代表已经验证所有种子、所有战术或长期难度平衡。
