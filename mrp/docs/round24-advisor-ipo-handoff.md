# 顾问研究导航与 IPO 决策边界（候选，2026-10-25）

## 基线与范围

基于 active main223500Z / round23 V8a 的独立文件副本。未改主源，未发布/部署，未推原 GitHub，未改服务器权限。此包不包含其他候选的研究树扩展或图像稳定性改动；合并时保留对应代理的文件/局部改动。

## 根因与已修复链路

- 研究：`home.followAdvice → applyAdvice → researchTech` 原先直接开研。现在手动入口只记 UI 推荐对象并打开 `tech` 页，原顾问 op 数据不变。`advice_navigation.researchRecommendation(S)` 返回推荐 id 或 null，供研究页候选展示高亮。导航不会修改研究任务或自动研究授权。
- IPO 顾问**原本已经只是去资本页**，并非直接上市；问题是资本页的一步启动、事件 start 一步执行，以及决策展示不足。现在顾问入口、资本页入口和 IPO 事件共用独立决策页。
- 页面展示与引擎校验共用 `ipoRequirements`：独立公司、尚未上市、无进行中 IPO、泡沫封锁、实际模式窗口、30 亿美元估值、重大诉讼；自洽/联机另列两个收入季度及近 12 个月客户收入。
- 史实：90 天后按当时估值的 8% 入账；现有引擎**不因 IPO 稀释 equity**，页面如实说明。
- 自洽/联机：现有 10/20/30% 发行比例，按届时估值 85 折发行，募资公式 `V * 0.85 * f / (1-f)`，持股乘以 `(1-f)`。页面比较不写状态；事件沿用原默认 20%，想换比例需暂缓后进资本页。
- 风险只写已有机制：没有主动取消入口、估值变化影响最终到账、泡沫破裂中断尚未完成 IPO、上市后股价波动。不新增承销费、审批概率、监管义务等机制。
- 明确确认才调用现有命令；确认时重新校验，报价/条件变化要求重新核对。等待远端期间连点去重，不乐观改本地；拒绝保留页面和原因。取消、返回、重入无游戏状态/存档写入。新导航替换面板时不重开或消费旧事件。

## 狭窄的引擎语义修正（不是 UI-only）

- 世界真人的 `ipo_window` 到期默认 `later`；收件箱提示同步。
- 真人掉线托管的 `resolveAll` 也暂缓 IPO，`botStep.freeOps` 不替真人自动发起 IPO。
- NPC 原自动上市不变；已有研究自动委托和其他模块不变；手动 `startIpo` / `startIpoIssue` / `resolveEvent` 仍走原权威命令入口，未扩权。
- 首次检查/存档格式/经济结算/随机数消费无新增机制；旧世界重放若含真人未确认 IPO 默认动作，可能因该明确修正而与旧版哈希不同。未重写历史基线来掩盖变化。
