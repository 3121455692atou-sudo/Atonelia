## A 起家（开局三选一）

### G01 微调开源底座起家
- **它代表什么**：
  - Vicuna-13B（2023-03-30）用约 7 万条 ShareGPT 对话微调 LLaMA，训练约 300 美元。用 GPT-4 当裁判，称达到 ChatGPT/Bard 质量的 90% 以上，作者自己说这个评测“不科学”。来源：https://lmsys.org/blog/2023-03-30-vicuna/
  - Perplexity 首批联网模型 pplx-7b/70b-online（2023-11）分别基于 Mistral-7B 和 Llama 2-70B 微调。来源：T:848
  - NovelAI Erato（2024-09）在 Llama 3 70B 上继续训练。来源：T:2059、EV:52
  - NovelAI Xialong（2026-03）在 GLM-4.6 上用自家小说数据加强化学习微调。来源：T:5899
- **前置**：开局时。世界上要有可商用的开放底座，Llama 2 社区许可从 2023-07 起允许商用（T:437）。2023-02 的 LLaMA 只有研究许可。
- **互斥**：G02、G03
- **效果构想**：
  - 首代模型立刻可用，成本极低。
  - 能力上限等于底座的各维度，只有专精维度能加 3~5。
  - 技术积累增长变慢。
  - 继承底座许可：研究许可底座不能商用。
  - 底座换代时触发“换底座”决策。
  - **命名钩子**：用 Llama 底座的模型名要带底座前缀，对照真实的“Llama 3 Erato”。许可条款要求本身未单独核实，置信 medium。
- **适合**：小型 LLM 初创、写作、搜索、角色扮演类公司

### G02 从零预训练（自研底座）
- **它代表什么**：
  - NovelAI Clio（2023-05-23）是它首个从零训练的小说模型，3B 参数、8K 上下文。来源：T:358、EV:50
  - NovelAI 的 H100 集群“Shoggy”在 2023-05 用于预训练。来源：https://en.wikipedia.org/wiki/NovelAI
  - Mistral 7B（2023-09-27）是该公司首个模型，就是自研的。来源：T:631
  - RWKV 社区一直自己训练 RNN 基座。来源：T:238
  - Kokoro-82M（2025-01）总训练成本约 1000 美元。来源：T:2685
- **前置**：开局时；自有或租用的算力达到门槛。
- **互斥**：G01、G03
- **效果构想**：
  - 首代模型晚 4–8 个月才出，花费高。
  - 技术积累增加。
  - 解锁“全新系列名”命名权。
  - 可以接 G10 非主流架构。
  - 这是 G12、G13 的硬前置。
- **适合**：有融资的 LLM 初创、语音和图像小模型公司、社区项目

### G03 蒸馏速成
- **它代表什么**：
  - Stanford Alpaca（2023-03-13）用 text-davinci-003 生成 5.2 万条数据微调 LLaMA 7B，数据成本不到 500 美元，训练不到 100 美元。因为 OpenAI 条款禁止开发竞争模型，只能用于学术。来源：https://crfm.stanford.edu/2023/03/13/alpaca.html
  - Sky-T1-32B-Preview（2025-01-10）用 QwQ-32B-Preview 蒸馏出约 1.7 万条数据，训练不到 450 美元。6 项基准里 4 项不低于 o1-preview，但 GPQA-Diamond 只有 56.8，o1-preview 是 75.2。来源：https://novasky-ai.github.io/posts/sky-t1/
  - DeepSeek-R1（2025-01-20）同时开源了 6 个蒸馏小模型。来源：T:2593
- **风险实例**：
  - OpenAI 在 2025-01-29 指控 DeepSeek 蒸馏它的模型。来源：T:8961
  - Anthropic 在 2025-09-04 禁止被不支持地区（如中国）公司控股超过 50% 的企业使用，理由之一是蒸馏。来源：https://www.anthropic.com/news/updating-restrictions-of-sales-to-unsupported-regions
  - Anthropic 在 2026-02-23 指控三家中国实验室用约 2.4 万个账户、超过 1600 万次对话做蒸馏。来源：T:10194、W:48
- **前置**：开局时；世界上有可调用的更强模型。
- **互斥**：G01、G02
- **效果构想**：
  - 出模型最快。
  - 每个维度的上限是老师对应维度 ×0.9~0.97，永远不能超过老师，也不能超过当期 SOTA。
  - 蒸馏依赖度起步就高。
  - 闭源老师会写入 `rights=tos`，有封号风险。
  - 中国公司在 2025-09 之后蒸馏 Claude 的难度提高。
  - **命名钩子**：模型名强制带“-Distill”后缀，对照 R1 蒸馏版的命名惯例（medium）。
- **适合**：缺钱的 LLM 初创；也适合作为 AI 对手的默认路线

## B 权重路线（意识形态：不能直接改，只能靠策略切换）

### G04 全面开放权重（社区优先）
- **它代表什么**：
  - Mistral 7B（2023-09-27）以 Apache 2.0 发布，官方说“可以无限制使用”，权重走 CDN 和 Hugging Face 下发。来源：T:631、https://mistral.ai/news/announcing-mistral-7b
  - Mixtral 8x22B 的权重在 2024-04-10 先用磁力链接放出。来源：T:1408
  - RWKV 全系开源。来源：T:238、T:1025、T:3041
  - Suno 的 Bark（2023-04）用 MIT 许可开源。来源：T:223
  - Fish Audio S2（2026-03）开源。来源：T:5757
- **前置**：开局可选，社区项目默认走这条；或者经 G07 切换过来。
- **互斥**：G05、G06
- **效果构想**：
  - 开发者口碑上升。
  - 定期出现“社区基于你的模型做了 XX”的衍生事件。
  - 你会进入别人的老师名单，别人蒸馏你没有风险。
  - API 定价权下降。
  - 不能开启严格防蒸馏。
- **适合**：RWKV 这类社区项目、想打响名气的初创

### G05 分层开放（开放核心）
- **它代表什么**：
  - BFL 的 FLUX.1（2024-08-01）分三档：[pro] 只走 API，[dev] 开放权重但限非商用，[schnell] 用 Apache 2.0。来源：T:1884
  - Mistral Codestral（2024-05）用“非生产许可”开放。来源：T:1547
  - Stability SD 3.5（2024-10）用社区许可，年收入 100 万美元以下可免费商用。来源：T:2177
  - Fish Audio Drama 3（2026-10）年收入 50 万美元以下可免费商用。来源：T:7821
  - Qwen3.8 底座（2026-08）的许可要求年收入超过 5000 万美元的服务商分成。来源：T:7046
  - 快手 Kolors（2024-07）商用需要登记。来源：T:1780
- **前置**：开局可选，或者已经有 2 代以上模型。
- **互斥**：G04、G06
- **效果构想**：
  - 旗舰 API 收入不受影响。
  - 小模型开源换口碑。
  - 按营收门槛向大客户收许可费。
  - 低概率出现“被批开源洗白”事件。
- **适合**：图像、语音、中型 LLM 公司

### G06 闭源 API / 订阅
- **它代表什么**：
  - Midjourney 所有版本都闭源。来源：RV:251-282
  - ElevenLabs 全系闭源。来源：T:517
  - Suno 开源 Bark 之后，所有歌曲模型都闭源。来源：T:223、RV:287-306
- **附属决策“遗产开源”**：NovelAI 在 2026-09-24 随 Clio、Krake 退役，把两者权重公开到 Hugging Face，Clio 用 GPL-2.0。来源：T:7556。闭源公司可以把退役满两年的旧模型开源换口碑，路线不变。
- **前置**：开局可选。
- **互斥**：G04、G05
- **效果构想**：
  - 有定价权，可以开启严格防蒸馏。
  - 社区口碑下降。
  - 反代和被蒸馏的风险上升。
- **适合**：面向消费者的图像、音乐、语音、写作公司

### G07 转向开源（改旗）
- **它代表什么**：
  - MiniMax 在 2025-01-15 开源 MiniMax-01，此前的 abab6.5（2024-04）是闭源的。来源：T:2573、T:1393
  - 月之暗面在 2025-07-11 开源 Kimi K2，此前 Kimi k1.5（2025-01）没开权重。来源：T:3991、T:2616
  - 百度在 2025-06-30 开源文心 4.5 家族的 10 款模型。来源：T:3919
  - Ideogram 在 2026-06 发布首个开放权重模型 4.0，权重为非商用许可。来源：T:6521
  - Gemma 4（2026-04）首次改用 Apache 2.0。来源：T:5944
- **前置**：当前处于 G05 或 G06。建议在 R1 冲击之后才能触发（W:30；英伟达单日暴跌约 17%，T:8947），或者在自家份额连续下滑时触发。
- **互斥**：G08，切换后有冷却期
- **效果构想**：
  - 口碑一次性暴涨，开发者生态扩大。
  - API 单价下降。
  - 完成后 `company.open = true`。
- **适合**：中型 LLM 和图像公司

### G08 收紧开放（闭源回撤）
- **它代表什么**：
  - Mistral 在 2024-02-26 推出首个闭源旗舰 Mistral Large，同一天微软 Azure 成为首个分发伙伴。来源：T:1140、T:8380
  - Mistral Medium 3（2025-05）闭源。来源：T:3527

- **前置**：当前处于 G04 或 G05；已经拿到大额融资或战略投资（G26/G27）。
- **互斥**：G07
- **效果构想**：
  - 旗舰定价权上升，可以开防蒸馏。
  - 触发社区反弹事件。
  - 可以选“旗舰闭源、小模型开源”的混合态。
- **适合**：拿了大钱的开源初创

## C 技术路线

### G09 小而精 / 端侧
- **它代表什么**：
  - 微软 Phi-1（2023-06）用筛选过的教材级数据和合成教材训练小代码模型。来源：EV:59
  - Kokoro-82M 只有 82M 参数，训练成本约 1000 美元。来源：T:2685
  - Gemma 3n（2025-06）最低 2GB 内存就能运行。来源：T:3884
- **前置**：G01 或 G02；数据质量达到门槛。
- **效果构想**：
  - 训练和推理成本都下降。
  - 会出现端侧合作事件。
  - 知识维度有上限。
- **适合**：语音公司、社区项目、小型初创

### G10 押注非主流架构
- **它代表什么**：
  - RWKV 是纯 RNN 路线：Raven（2023-04）见 T:238；RWKV-7（2025-03）推理时每个 token 的内存占用恒定，见 T:3041、EV:31。
  - Cartesia Sonic（2024-05）基于 SSM，自称模型延迟 135ms。来源：T:1562
  - MiniMax-01 大规模采用线性注意力，上下文 400 万 token。来源：T:2573
  - LLaDA（2025-02）从头训练扩散语言模型。来源：EV:61
  - Qwen3-Next（2025-09）训练成本约为 Qwen3-32B 的 10%。来源：T:4540
- **反面例子**：RWKV 到 2026-08 才首次提供官方 Transformers 格式权重。来源：T:6987
- **前置**：必须先走 G02。
- **效果构想**：
  - 长上下文和推理成本有大优势。
  - 首创者可以给架构起名。
  - 生态兼容慢：量化和第三方工具支持滞后，开发者采用率下降。
  - 有研发失败的概率。
- **适合**：社区项目、语音公司、研究型初创

### G11 模型合并 / 进化合并（“少量提升”的手段之一）
- **它代表什么**：Sakana AI（2024-03-21）用进化算法合并现有模型，不做任何梯度训练，合出 EvoLLM-JP。作者称它在 9 项日语任务上的均分超过此前 70B 的最好成绩。来源：https://sakana.ai/evolutionary-model-merge/
- **前置**：G01 或 G04（需要有多个开放权重模型可合并）。
- **效果构想**：
  - 几乎零训练成本，几周内单一维度提升 1~3。
  - 在窄领域可以略超父模型，但综合能力不超过最强父模型。
  - 不增加技术积累。
- **适合**：社区项目、小型初创

### G12 自研强化学习 / 推理后训练
- **它代表什么**：
  - DeepSeek-R1（2025-01-20）对标 o1。来源：T:2593
  - MiniMax-M1（2025-06）的 RL 阶段只用了 512 张 H800、三周，租用成本约 53.47 万美元。来源：T:3819
  - Kimi k1.5（2025-01-20）。来源：T:2616
  - s1（2025-01-31）只用 1000 条数据加测试时扩展，竞赛数学比 o1-preview 最多高 27%。来源：https://arxiv.org/abs/2501.19393
- **前置**：G02，或者已有一代以上自研底座；世界里已出现“推理模型”科技（W:26，2024-09）。
- **效果构想**：
  - 推理和数学维度上限提高，蒸馏依赖度下降。
  - 是 G13 的必经前置。
- **适合**：LLM 初创

### G13 青出于蓝（隐藏终局：超越当期 SOTA）
- **现实依据**：现实中几乎没有蒸馏模型或小厂全面超越当期 SOTA 的例子。
  - R1 对标的 o1，在 R1 发布前一个月的 2024-12-20 就已被 o3 预告超过（T:2514）。
  - Sky-T1 追平的 o1-preview，在 2024-12-05 已被 o1 正式版取代（T:2363）。
  - Llama 3.1 405B（2024-07）也只是“首次逼近闭源前沿”（T:1830）。
  - 厂商自称超越 SOTA 的，多半只是部分评测。例如 Qwen3.8-Max（2026-08）称部分评测超过 GPT-5.6 Sol 和 Claude Fable 5（T:6948）。
- **前置**（建议极严）：
  - G02 + G12
  - 蒸馏依赖度 ≤5%，没有任何 `tos` 或 `pirated` 数据
  - 连续两代自研底座
  - 原创技术 2 项以上
  - 训练算力达到 SOTA 实验室的 30% 以上
  - 技术积累处于顶级档
- **效果构想**：
  - 只允许一个维度超过当期 SOTA 1~3 点，其他维度仍然封顶。
  - 触发全球事件。
  - AI 对手的触发权重在 0.5% 以下。
- **适合**：仅玩家

## D 商业化

### G14 自举订阅（不融资）
- **它代表什么**：
  - Midjourney 创始人在 2022-08-01 说公司“自筹资金、没有投资人”，已经盈利，约 10 人。来源：https://www.theregister.com/2022/08/01/david_holz_midjourney/
  - 到 2025-08-22，Midjourney 仍然从未接受外部融资。来源：https://techcrunch.com/2025/08/22/meta-partners-with-midjourney-on-ai-image-and-video-models/
  - NovelAI 是付费订阅服务，2021-06 上线。来源：https://en.wikipedia.org/wiki/NovelAI
- **前置**：首个产品上线，且月收入大于月支出。
- **互斥**：G26、G27
- **效果构想**：
  - 股权不被稀释，士气上升，决策自由。
  - 算力扩张慢，无法参与超大规模训练。
  - 破产事件的概率下降。
- **适合**：图像、写作、音乐小厂

### G15 开发者 API 平台（含上架网关）
- **它代表什么**：
  - Mistral 在 2023-12 发布 Mixtral 时同期开放 API 平台。来源：T:902
