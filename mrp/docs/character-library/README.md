# ZipZipPipe 角色收录与核验范围

截至 2026-10-19，核对公开动态 144 条，覆盖 AI 拟人创作开始的五月至十月。另逐张检查五月九日四组共 28 张早期底图，并与八月两批设定比较；相同图像以哈希去重，同角色的大小比例、换装、表情归为同一角色。

本版本收录 25 位可育成模型和 16 位 NPC（14 位工具、2 位设施）。只有模型可以育成；工具与设施角色可拜访互动，不参加训练或比赛。Fable 5、JEV、DeepSeek Pro/Flash 分别保留。作者在九月二十九日标明的无关原创角色、薇拉等个人 Agent/龙族 OC、同人视频内重复角色及纯节庆换装不计作新模型。Git、操作系统和云厂商等非 AI 模型角色未进入本次模型清单；应用角色额外加入了与本次接入玩法相关的伙伴。

完整名称、类别、资产路径和原帖见下表。records 中保存图像观察与游戏改编的区分，sources 保存出处与核验回执；index/records.jsonl 可从当前 Markdown 重建。DeepSeek 鲸鱼形象按 CC BY-NC-SA 4.0 保留上善无形与 ZipZipPipe 署名，其余未推定统一授权。
