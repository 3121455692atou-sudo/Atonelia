# 数据/研究托管 M1 试用（独立副本）

此目录冻结自 2026-10-23 10:23 的候选版，只在此副本增加功能。没有并入 root candidate，也没有改 live server。

## 实点入口

1. `python3 serve.py` 或指定静态服务端口打开本目录。
2. 新开史实局，选公司页面点“数据/研究托管试用：开启”；推荐 DeepSeek / 2025，初始事件正常处理。
3. 进入游戏后在后台“其他→托管”看两项auto。关闭后台推进一个游戏日，再看日志。
4. 基准fixture seed13可见真实数据订单 `ds_swe_env`（$3M/30天）和真实 `mcp` 研究。UI随机seed/选择不同可产生不同合法建议，不保证这两个id。
5. 数据/研究可分别手动；切手动不会取消已有订单/研究。每天最多各执行一项，后续游戏日才重新决策。
6. 旧局导入不会开托管；在后台明确点“启用”才升级。单人自洽局同样可在后台启用，仅真人公司。多人入口明确未接入，命令层也拒绝。
7. 真实回归重点：启用→推进→查看真实数据页订单/研究页项目；刷新/继续同日不重复；手动后次日不增新项目而旧项目继续；省钱实际降低共享预算；不开启的旧局原样运行。

## 约束

- 只有data/research是真自动；算力、预训练、经营、发布、策略节点、卡牌收益都没有接入。卡牌偏好manual仅声明，不代替卡session真实实现。
- 不接受客户端advice任意op。数据只允许干净静态包，不含生成/API/恢复暂停；研究走真实researchTech，启动无额外现金成本但正常占研究槽/时间。
- 共同预算：日初现金15%且保留最近净支出12个月；省钱5%。数值是M1显式试用初值，未做长周期经济校准，不称平衡完成。
- 唯一tickDay入口；JSON存档保留lastDay/cursor/配置receipt，重复日调度无副作用。单机浏览器正常存档一致性；不声称跨存储失败具备服务器WAL保证。
- 旧档不添字段；新字段仅显式启用。已终局、未知版本、损坏托管状态、多人模式均不执行。
- 现有公开顾问预测口径未改动。未来精确信息是否属于既有公开预测仍是专项审计事项，没有新增窥探。
