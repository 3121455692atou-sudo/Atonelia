一个在网页上玩的 AI 模型公司经营模拟，按天推进。你挑一家公司，找数据、买卡、立项炼模型、送评、发布、卖服务、融资上市，看能不能写出比现实更好的一条线。

## 三种玩法

- **单人 · 史实**：扮演 24 家真实公司之一，从 2023、2024、2025 或 2026 年 1 月开局，一直经营到 2026 年 10 月。对手按真实的发布数据出牌，行业大事、显卡交期、股价也按真实月份走。
- **单人 · 自洽世界**：从零开局，或者从 2023、2024、2025 年的真实局面分岔出去。你和几家电脑公司同一套规则：谁最强、谁先公开技术、市场多大、股价多少，全由各家的行为算出来。
- **联机**：一台权威服务器按天结算，2–8 个人加电脑公司在同一个世界里训练、起名、打榜、炒股。

## 核心机制

- **公司策略树**：像钢铁雄心的国策树。同一时间只推进一项，几十天后完成，换来公司特质、某个史实型号名的使用权，或者改变开源路线。换项时旧进度保留 30 天，换回来能接着做。
- **开源路线与授名**：路线分五档，只管旗舰开不开源，只能靠策略改；小模型发布时自己选。模型名字由你起；「DeepSeek-R1」这类史实型号名，要先完成对应策略、模型达标、这一代训练干净（没炸过）才用得上。
- **训练作业**：预训练、蒸馏小模型、续训、后训练、试验是不同的作业。能同时跑几项，先看卡，再看作业位（按团队人数和自有卡数取大）。卡在出租、推理、训练之间由你分，训练卡再按「优先 / 正常」自动分给各项作业；放不下最低卡就排队。
- **评测与发布**：发布前把在练的模型送评，候选当场冻结（名字、开不开源、附不附技术报告一起定）。评测按日历天走，不占卡，期间接着练下一版；标准档 14 天，快速档 7 天。也可以跳过，代价是固定的一笔风险。
- **SOTA 标签**：每个模态同一时间只有一枚，大小模型、开闭源一视同仁，只比综合分。别家要比现任高出 0.1 才换手；炼出过 SOTA 的公司，市场会一直把它当冠军，这个身份不会过期。
- **市场期待**：每次发布旗舰，市场按你的身份（冠军、挑战者、小团队）打一次分，结果分五档，奖惩只结算一次。
- **董事会目标**：按公司量级给的阶段目标。到期没达成有两个月宽限，再不达成记一次警告，累计三次被换掉。
- **融资与 AI 泡沫**：AI 公司主要靠融资活着，推理成本、人才溢价、折旧会吃掉大部分毛利。到泡沫检查点，没能连续三个月盈利的大公司会遇上泡沫破裂：估值腰斩、融资关 180 天、需求下降，目标变成「活下去」。
- **股市**：史实模式看真实月末收盘价；自洽和联机里，上市公司有自己的做市池，可以买入卖出、做空回补，也有上市、增发和回购。

## 怎么跑

单机运行需要 Python 3 和浏览器；测试、校准与联机需要 Node.js。原生 HTML、CSS、JavaScript，没有构建步骤，改完刷新页面就生效。

**单机版**：

```sh
npm start
```

等于 `python3 serve.py`，起一个只监听本机的静态服务器，地址是 http://127.0.0.1:8765/ 。

**联机服务器**：

```sh
node server/mp.mjs --port 8790 --host 127.0.0.1 --data ./mp-data
```

零依赖，只用 Node 自带的模块。参数都有默认值，直接 `node server/mp.mjs` 也行：端口 8790、只监听本机、最多 4 个房间、数据目录默认是仓库下的 `mp-data/`（第一次启动时自动建好，已在 `.gitignore` 里）。`--time-scale` 缩放全部计时，默认 1。服务器起来后，浏览器打开 http://127.0.0.1:8790/ ，在标题页点「联机」建房或加入。

**测试**：

```sh
npm test
```

用 Node 自带的测试跑 `tests/` 下的全部测试；测试数量与通过、失败、跳过情况以本次实际输出为准。全量回归通过不等于独立性能、长局或真实浏览器验收全部通过。

可选的浏览器烟测：先 `npm start`，再 `npm run test:ui`。它用无头 Chromium 在 1440 和 390 两种宽度下真点界面；本机没装 Playwright，或装了却找不到 Chromium 时，只提示一句就正常退出。

**存档**都在浏览器里：史实局 `mrp.sim.v2`、名人堂 `mrp.sim.hof.v2`，自洽世界另外存一份。设置页可以导出和导入存档。

## 校准和检查脚本

都在仓库根目录跑，参数不写就用默认值。输出逐行打印，退出码非 0 表示有检查不过。

- `node scripts/fingerprint.mjs --check`：行为指纹。24 家公司 × 4 个剧本，机器人和「下一步」大按钮各一局，共 192 局，和基线逐局比哈希；有不一致就列出是哪几局。`--write` 重存基线（要先在 `docs/fingerprint-changes.md` 登记原因），`--diff` 打印某一局第一处不同的路径。
- `node scripts/smoke.mjs`：整局冒烟，同样 192 局。每局要求不抛错、不卡死、终局没有坏数值、中途和终局存档读回来一模一样。
- `node scripts/world_smoke.mjs`：自洽世界冒烟。从零开局 3 种年份 × 3 种规模 × 3/6/12 家，各跑 730 天，打印换手次数、最长停滞天数、每年涨幅和报错数；`--perf` 只量性能。
- `node scripts/selfplay_calibrate.mjs --seeds 8`：自洽世界校准，240 个世界（含分岔局），输出验收表里能算的每一行；`--perf` 只量 12 家和分岔 20 家跑 730 天的耗时。
- `node scripts/mp_soak.mjs`：联机浸泡。6 个无头客户端加 2 家电脑，最快档打完 730 天，看重放哈希、单日耗时和每个客户端的下行流量。
- `node scripts/check_unused.mjs`：死导出检查。`src/career` 里没人用的导出会列出来，退出码 1。
- `node scripts/calibrate.mjs [--seeds 3] [--advisor]`：平衡校准。让机器人在每家公司、每个剧本各玩几局，汇总结局、评级和里程碑达成率；`--advisor` 改成每一步照着「下一步」大按钮做。

`scripts/` 里其余的是数据生成脚本（发布日、股价、学界起点、里程碑文案等）、剧本文案生成和图标导入，一般不手动跑。

## 代码地图

入口只有一条链路：`index.html` 加载 `src/career/ui/bootstrap.js`，完成引导存档隔离后再加载 `src/career/ui/app.js`，界面和测试都从 `src/career/engine.js` 用引擎，引擎里是纯逻辑，不碰页面。

### 入口和基础

- `index.html`：页面骨架，按顺序引用 `src/career/css/` 下的样式表，最后加载界面入口。
- `src/career/engine.js`：引擎唯一出口，只做转出口。
- `src/career/ui/app.js`：启动、标题页、剧本选择、屏幕切换、时钟。
- `src/career/sim/game.js`：开一局，开局阵容和开局持卡。
- `src/career/data/core.js`：时间、模态、规模、硬件、技术、产品、公司这些基础设定。

### 训练与模型（`src/career/sim/`）

- `model.js`：模型能力、结构、底座和蒸馏的数值、后训练、跑分与排行榜。
- `projects.js`：预训练、蒸馏、续训的立项检查，炼完出模型，中止和取消。
- `jobs.js`：训练作业表、分卡、作业位、检修。
- `lab.js`：小规模试验（调参、验证架构、数据配比），成功时下一代底座省算力。
- `data_ops.js`：数据市场、蒸馏老师、生成订单的下单和到货入库。
- `orders.js`：在途订单的排队和交付，生成订单的进度、暂停、取消。
- `compute.js`：买卡、租卡、季度配额、灰色渠道、卖卡退租、推理份额。

### 评测与发布

- `evals.js`：送评、冻结候选、安全评测。
- `release.js`：跑分、发布流程、技术报告、灰度上线。
- `naming.js`：起名规则和校验、建议名、史实型号名授权。
- `expect.js`：市场期待的判定。
- `sota.js`：「谁最强」和 SOTA 标签的唯一算法。

### 经济与资本

- `economy.js`：服务收入、财务、行情。
- `capital.js`：股票交易、融资、上市，以及到期结算。
- `bubble.js`：AI 泡沫的检查和破裂后果。
- `reputation.js`：口碑、品牌，反代和偷偷分流的证据。
- `legal.js`：立案、诉讼进度和判决。
- `service.js`：产品开关、价格档、出租、分流，国内对话产品的备案。

### 事件与策略

- `strategy.js`：策略树、节点状态、前置、互斥、绕过、公司特质。
- `strategy_ai.js`：顾问和机器人怎么挑策略、要不要蒸馏、发布时间。
- `route.js`：开源路线五档，唯一的写法。
- `exclusive.js`：各家公司的专属事件。
- `events.js`：按局面触发的经营事件。
- `milestones.js`：里程碑判定，谁先做到算谁的。
- `milestone_view.js`：里程碑卡片和选项。
- `super.js`：超事件，以及选项里的真实操作。
- `world.js`：行业大事落到这一局，榜单换题。
- `queue.js`：事件队列、弹窗预算、台词名牌、行业大事短剧。
- `cond.js`：条件判断，策略、授名、事件共用一套写法。
- `effects.js`：效果结算和选项提示，只有一份来源。
- `modifiers.js`：技术、路线、特质、限时加成的统一读数。

### 推进、目标与工具

- `loop.js`：按天推进、月结、月初，和做决定的总入口。
- `clock.js`：按天推进用的日期工具。
- `board.js`：董事会目标的生成和结算。
- `finish.js`：终局结算和评级。
- `advisor.js`：「下一步」大按钮的建议。
- `bot.js`：自动对局机器人，给测试和校准用。
- `provider.js`：世界读取的接缝，史实模式由它包住写死的数据。
- `commands.js`：唯一一张命令参数表和一个执行入口，界面和联机服务器共用。
- `migrate.js`：当前 v5 存档的结构/数值校验入口；不迁移旧档，旧版必须新开局。
- `log.js`：公司日志。

### 自洽世界（`src/career/world/`）

- `index.js`：世界总入口，从零开局、两段式日结、公开视图和私有视图。
- `sim_provider.js`：自洽世界里所有「世界是什么样」的读取。
- `label.js`：全世界只有一份的 SOTA 账本。
- `tech.js`：全世界一本技术账本，技术公开到什么程度由各家行为决定。
- `academia.js`：学界和开源社区这个 NPC 发布者。
- `market.js`：客户市场的份额和市场规模。
- `supply.js`：共用的算力供给、季度配额、季末统一价、租卡池。
- `valuation.js`：基本面估值、公司档位、指数。
- `triggers.js`：行业大事触发器（价格战、开源冲击、出口管制、反垄断、版权官司）。
- `names.js`：世界名字账本，名字全世界唯一，送评时先到先得。
- `goals.js`：自洽世界的董事会目标判定。
- `bots.js`：电脑公司。
- `exchange.js`：股市的做市池、买卖、做空、上市。
- `distill_watch.js`：闭源 API 蒸馏的限流、检测和指控。
- `license.js`：受限开源条款。
- `poach.js`：挖人。
- `transfer.js`：公司之间的钱。
- `restructure.js`：破产、重组、清算。
- `release.js`：往世界发布表里追加。
- `mirror.js`：联机客户端拿服务器推来的公开视图拼一个只读世界。
- `save.js`：世界存档和浏览器存储。

### 联机

- `src/career/net/protocol.js`：联机协议，路由、推送事件、错误码、差分格式。
- `server/mp.mjs`：服务器主进程，HTTP 接口、静态文件、每间房一个 worker。
- `server/room.mjs`：一局一个 worker，大厅、座位、时钟、托管。
- `server/store.mjs`：联机存档，先写日志再改世界，快照可以丢。
- `server/static.mjs`：只给仓库里的游戏文件。

### 数据（`src/career/data/`）

- `balance.js`：平衡常量。
- `routes.js`：开源路线五档和各家开局路线。
- `strategy_core.js`、`spirits.js`：策略的共享主干和通用公司特质。
- `companies/`：24 家公司各一棵史实策略树，加 4 棵模态通用树和校验器。
- `expect.js`：市场期待的奖惩表。
- `rivals.js`：模型家族和真实发布时间线；`release_days_gen.js`、`release_days_overrides.js` 是每条发布的日期。
- `model_structure.js`：历史型号的参数结构解析。
- `benchmarks.js`：榜单定义和分数换算。
- `datasets.js`：数据市场。
- `techsrc.js`：每项技术在现实里是怎么传开的。
- `supply.js`：交期和季度配额。
- `economy.js`、`exchange.js`：经济常数；自洽和联机专用的股市、转账、指控、挖人常数。
- `selfplay.js`、`academia.js`：自洽和联机的默认值、学界起点表。
- `stocks_gen.js`、`hardware_gen.js`：真实股价、显卡照片署名，由脚本生成。
- `world.js`：行业大事、市场规模与行情。
- `events.js`、`super.js`：经营事件和超事件的文案与选项。
- `goals.js`：董事会目标模板和阈值。
- `milestones.js`、`milestones_gen.js`：里程碑和文案。
- `history.js`、`history_facts.js`、`history_gen.js`：史实对照和短剧。
- `roster.js`、`credits.js`：角色名册和美术鸣谢。
- `strategy_icons.js`：策略节点的图标清单。

### 界面（`src/career/ui/`）

- `state.js`：界面共用的状态和弹层，用来避开循环导入。
- `storage.js`：存档、名人堂、自洽世界存档的本地读写。
- `topbar.js`、`home.js`：主界面顶栏和主界面。
- `office.js`：后台外壳，左边导航、右边当前页。
- `flow.js`：主流程里的做决定和处理事件；`act.js`：界面的写操作统一走命令表。

- `chat.js`、`vn.js`：图鉴里的对话、事件播放。
- `bench.js`、`charts.js`、`fmt.js`：跑分演出、图表的 SVG 绘制、格式化和美术资源。
