## 当前内容

- 主页直接进入后训练和模型训练，点击后选择模型与训练内容。
- 新手引导从真实游戏主页开始，依次学习训练入口、安排训练、配卡出牌和推进时间。
- 卡包支持点击收纳与取回，使用完整卡面；每回合三选一。
- 选择公司后，可在同一页设置自动或手动玩法并开始游戏。
- 包含游戏源码、运行资源、联机服务器、测试和校准脚本。

## 本地运行

单机运行需要 Python 3 和浏览器，无需安装前端依赖，也没有构建步骤。

```sh
git clone https://github.com/3121455692atou-sudo/Atonelia.git
cd Atonelia/mrp
python3 serve.py
```

打开 **http://127.0.0.1:8765/**。请通过本地服务器访问，不要直接双击 `index.html`。

Node.js 用于测试、校准和联机：

```sh
cd mrp                       # 从仓库根目录进入游戏目录
npm test                     # 完整测试
node server/mp.mjs --port 8790 --host 127.0.0.1 --data ./mp-data
```

联机服务器默认只监听本机；多人远程访问需要自行配置部署。ChatGPT.site 在线版为静态单机页面。

正式存档保存在浏览器中。新手引导使用独立的临时存档，退出后不保存，也不会覆盖正式存档。
