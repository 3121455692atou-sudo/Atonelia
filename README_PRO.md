# 《模型育成计划》v1.0：请帮忙解决的几个难题

你是这个项目的资深工程师兼游戏平衡设计师。游戏是 AI 模型公司经营模拟：网页游戏，纯 ES 模块，没有构建步骤，引擎按天推进。三种玩法：史实（2023–2026 按真实月份，玩家扮演一家真实公司）、单人自洽（从零开局的虚构世界）、联机（权威服务器按天结算，多人同场）。

**如果沙盒能跑 Node（请先 `node --version`；我本机是 Node 26），请真的跑模拟验证你的方案，宁可多跑几轮。** 跑不了就用静态分析，并说明哪些结论没有验证。

## 仓库里有什么
- `mrp/`：游戏仓库的完整快照（v1.0，原仓库提交 6b2f98f），含美术素材、史料时间线、决策记录、规格附带的核验工具（`docs/spec/tools/`）。在干净目录里 `npm test` 1269 项全过。**这个公开仓库的第一个提交就是基线**：你的改动都在 `mrp/` 里做，最后 `git diff <第一个提交> -- mrp calib > fix.patch`。
  - `mrp/src/career/`：引擎（`engine.js` 总出口；`sim/` 单人史实；`world/` 自洽世界和联机世界；`data/` 数值表；`net/protocol.js` 联机协议）；`mrp/server/`：联机服务器；`mrp/content/`：史实数据。
  - `mrp/README.md`：代码地图。`mrp/docs/spec/v1.0-spec.md`：规格（很长，按题目给的章节读）。`mrp/docs/NEXT.md`：施工日志，最上面两节是最近的校准记录和“还没做的”。
  - 检查：`npm test`（约 1270 项）；`node scripts/fingerprint.mjs --check`（史实行为指纹 192 局，改行为就会变，允许，但要在 `docs/fingerprint-changes.md` 按格式登记再 `--write`）；`node scripts/smoke.mjs`；`node scripts/world_smoke.mjs`；`node scripts/selfplay_calibrate.mjs --seeds 8`（自洽 F4a 全表）；`node scripts/mp_soak.mjs`（联机浸泡）。
- `calib/`：F4 校准脚本和探针（在 `calib/` 目录里运行，脚本按相对路径找 `../mrp`）。
  - `calib/run_f4.sh <输出目录> [种子数]`：机器人（`playGame`）和大按钮（照顾问 `advise()` 玩，`playAdvised`）各 384 局（24 家 × 4 剧本 × 4 种子），汇总到 `<输出目录>/f4.txt`。8 核约 4 分钟；种子 1 可快速试。
  - `calib/grants_all.mjs <仓库> <种子数> <公司,…>`：授名统计（每个授名在史实日 ±6 个月内用上的比例）。`calib/goal_detail.mjs`、`calib/goal_rates.mjs`：董事会目标在截止日的要求和实际。
  - `calib/results/`：当前代码的 F4 全表（`f4.txt`）、自洽全表（`selfplay.txt`）、授名统计（`grants_*.jsonl`）。

## 全局约束
1. **不许刷数字**：不为了让统计过线加特判加成、给某家公司开后门。每个改动要能用游戏设计或真实历史讲通。
2. **不能变坏的线**（规格 F4、F4a，现在全部达标，见 `calib/results/`）：机器人评级 S+A ≤ 12%（现在 11.5%，离线最近）、C–E ≥ 55%、F+G ≤ 12%、撤换 ≤ 8%；大按钮 S+A ≤ 20%、B–D ≥ 60%、撤换 ≤ 6%；各拿标桶的区间；“护栏：自家最强比史实高 3 分以上的天数 ≤ 5%”；“领先第二名 ≥ 3 分的天数 ≤ 2%”；弹窗 ≤ 1.5 张/月；自洽 F4a 各行（大按钮真人进前一半 50–80%，现在正好 50%）。
3. **经济方向不能变**：AI 公司主要靠融资活着，几乎不可能盈利（大公司盈利是隐藏成就级别）；2026-06-01 的 AI 泡沫破裂只有大公司连续 3 个月盈利才能躲过。
4. 顾问只推荐正当做法（不推荐刷榜、偷偷降智、违规蒸馏、走私）。
5. 注释、界面文字都是中文，注释写“为什么”；风格跟周围一致。

## 题目（可以只做其中几题；每题单独给结论和补丁）

### 题 1：电脑公司 2025 年整体弱于史实，DeepSeek y2024 的 R1 授名 0/8
- F4“授名率”一行要求 DeepSeek y2024 剧本的 R1 授名 25–60%（其余三行已达标）。现在 8 局全作废：2025-02 拿到授权后，电脑的在练模型只有 72 分、数学 72，条件要数学 85、离当前最强（82–85）不超过 3 分，还没学会推理；2025-04-29 Qwen3 拿走“开源推理追近前沿”，授权作废。
- 更广的现象：P3.T 授名统计（±6 个月内用上）只有 62/105 达标，原因多是电脑练得慢、立项不够大胆。P1.2 加了难度曲线以后，电脑在 2025 年普遍落后史实一截。
- 读：规格 D6（难度曲线）、D9、T9.1（电脑训练作业）、A10（电脑规则、授名时机）、C3（授名条件）；`sim/bot.js`、`sim/strategy_ai.js`、`sim/model.js`、`data/companies/deepseek.js`。
- 要：查清电脑在 2024 下半年到 2025 年慢在哪（立项时机、底座规模、后训练方向、研究顺序、算力），给出讲得通的改法，让 DeepSeek y2024 的 R1 进 25–60%，同时第 2 条的线不能坏（尤其 S+A ≤ 12% 和护栏）。

### 题 2：`advise()` 单次 < 2 ms
- F4 性能线“`advise()` 单次 < 2 ms”。现在单独量平均 0.65 ms，但 4.9% 的调用 ≥ 2 ms（`calib/f4_metrics.mjs --mode adv --seeds 1 --only qwen,deepseek,gemini,claude,gpt,kimi,glm,grok` 汇总里的 advN/adv2）。
- 超线的全是 `sim/advisor.js` 的 `projectAdvice`：每周换日以后第一次调用要重建“候选底座表”（`candTable`：架构 × 总参 × 激活 × token 约 900 个配置，每个过 `projectCheck`、`previewProject`），“为目标换底座”时还要对每个候选算练满上限 `baseCeiling`。同一天里输入不变时已经按键缓存。
- 要：**不改任何结果**（16 局大按钮 + 16 局机器人的整份终局状态哈希必须和改前一致；`calib/` 里没有哈希脚本的话自己写一个：`JSON.stringify(playAdvised(...).s)` 取 sha256）把 ≥ 2 ms 的比例压到 0，或者给出证明为什么做不到、最少要改哪条行为。思路举例：底座分 q 对 token、规模是否单调，能不能分支定界跳过整片候选；`llmBase` 能不能拆成可复用的部分。

### 题 3：上线前审查联机服务器
- 联机服务器（`server/mp.mjs`、`server/room.mjs`、`server/store.mjs`、`server/static.mjs`，协议 `src/career/net/protocol.js`）准备部署到公网 VPS（反向代理后面）。规格 M.6（尤其 M.6.5 命令表、M.6.7 断线重连、M.6.9 房间设置、M.6.10 部署）。
- 要：从安全和稳健两方面审：越权（拿别人座位、看到别人私有数据）、注入和路径穿越、资源耗尽（大请求、慢请求、SSE 连接数、房间数、日志和快照无限增长）、崩溃恢复、时间和随机数可否被客户端操纵、重放一致性。按严重程度列出问题，每条给复现步骤和补丁；补丁要配测试（`tests/server/`）。

### 题 4：经济设定里几条没定的（设计建议为主，可附补丁）
- 史实局泡沫破裂后电脑公司全部活到终局（电脑一直留 18 个月以上现金跑道），“活下去”目标几乎没有压力。规格 K5 没有存活率的线。
- 融资轮按估值的 8% / 15% / 22% 出让，大公司一轮动辄上千亿，要不要收窄。
- 芯片厂入股 AI 公司再卖卡给它（循环交易）还没做，值不值得做、怎么做才不变成刷钱。
- 自洽世界里中国公司照大按钮玩进前一半是 0/6（本土市场小、买卡受管制），要不要、怎么收窄。
- 读：规格 K 章全部、M.3（自洽）、`sim/capital.js`、`sim/bubble.js`、`world/supply.js`、`data/economy.js`。
- 要：每条给建议（参考真实 2023–2026 的 AI 融资和泡沫讨论），说明对哪些 F4/F4a 行有影响；有把握的给补丁并跑校准。
